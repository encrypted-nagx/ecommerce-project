🔐 CyberVault – Full Stack E-Commerce Website
A modern Full Stack E-Commerce Website built for Cyber Security products, developed from scratch using HTML, CSS, JavaScript, Node.js, Express.js, and MySQL.
The project demonstrates complete frontend-backend integration, cloud database connectivity, REST APIs, and deployment on modern cloud platforms.

🚀 Live Demo
🌐 Website: https://ecommerce-project-eight-bay.vercel.app/products.html
💻 GitHub Repository: https://github.com/encrypted-nagx/ecommerce-project

📌 Project Overview
CyberVault is an online shopping platform that allows users to browse cybersecurity products, add them to a cart, place orders, and enables administrators to manage products and customer orders through an admin panel.
The project was fully developed and deployed as a real-world Full Stack Web Development project.
